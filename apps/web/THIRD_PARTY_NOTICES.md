# Web font notices

Caselog bundles the following fonts with the self-hosted web application:

| Font | Bundled source | License | License text |
| --- | --- | --- | --- |
| Figtree | `public/fonts/figtree-latin.woff2` | SIL Open Font License 1.1 | `public/fonts/OFL.txt` |
| IBM Plex Mono 5.3.0 | `@fontsource/ibm-plex-mono` | SIL Open Font License 1.1 | dependency package `LICENSE` |

The fonts are loaded locally. The production application does not request them from a
third-party font CDN.
